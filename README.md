# doniarmans.github.io

Personal portfolio of Doni Arman S, hosted on GitHub Pages at https://doniarmans.github.io.

Plain HTML, CSS and JavaScript, no build step. Edit `index.html` and push to `main`; the site updates within a few minutes.

- `index.html`: content and SEO tags
- `styles.css`: layout and colours (the blue `#2e7df6` is the portrait's background)
- `main.js`: draws the chessboard behind the portrait and plays the knight's-tour reveal
- `assets/board-mask.png`: the portrait's background as a mask, so the board sits behind Doni
